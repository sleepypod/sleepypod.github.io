# About Sleepypod

Sleepypod is an independent, community-built ecosystem for local control of Pod hardware. Core, the native iOS app, and the M5 Rotary Dial share a local connection so you can choose the interface that fits your routine.

## Open source

Core and iOS are licensed under AGPL-3.0. The M5 Rotary Dial firmware is MIT licensed and builds on [dallonby/RotaryDial](https://github.com/dallonby/RotaryDial). Refer to each repository's license for its terms.

The project is not affiliated with Eight Sleep, Apple, or M5Stack. Product names identify compatible hardware and platforms.

## About these guides

The documentation is grounded in the linked product repositories. Source references at the bottom of each guide pin the material used to write it. The installed application's generated API contract takes precedence for exact request schemas.

Product screenshots and demonstration clips are captured from real interfaces. They illustrate a particular product revision, so details can differ from newer builds. Media provenance and reproduction steps live in the [capture guide](/developers/media/).

## Contribute

[Improve these docs](https://github.com/sleepypod/sleepypod.github.io), report a product issue, or join the [community Discord](https://discord.gg/UMmv5R6MXa).

This site is a static Nextra build hosted on GitHub Pages. Search runs in your browser with Pagefind; the site does not connect to your Pod or collect your sleep data.
