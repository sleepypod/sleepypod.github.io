# Return to stock with official OTA

<Callout type="error">

**An official update ends root access.**

Pairing with the official app installs Eight Sleep's current firmware, which patches the bootloader. The [serial root-access procedure](/core/root-access/) no longer works afterward. Do not count on regaining root access or reinstalling sleepypod.

**Do not use this method if you plan to keep root access or run sleepypod.** Only follow these steps if you are returning the device permanently to stock operation and will only use the official Eight Sleep service.

</Callout>

For matched hardware returning to stock, a hardware factory reset restores the factory image whether or not you synchronized Slot B. **It also erases the `persist` partition: your settings, biometrics, and HomeKit pairing.** If you need to keep root access, use [the manual subsystem update](/core/firmware-updates/manual-update/) only for a supported subsystem update.

1. **Perform a hardware factory reset:**
   Follow the firmware reset photos for your model in [free-sleep's installation guide](https://github.com/throwaway31265/free-sleep/blob/e5172139874a274d1ced12c8da052ab2cbaa286d/INSTALLATION.md). The hub boots a recovery image that reformats both root filesystem slots and the `persist` partition, reinstalls the factory image from the `firmware` partition into both slots, and resets network settings. Slot B is not the factory backup, so synchronizing it does not change what the reset restores.
2. **Pair with the official Eight Sleep app:**
   Pair the Pod to the official mobile app over Wi-Fi. Allow the hub to connect to Eight Sleep's servers and download official over-the-air (OTA) updates until all firmware and subsystem updates finish applying.

<Callout type="info">

**Hardware limitation:** Official OTA may not update cross-generation pairings, such as a Pod 3 hub with a Pod 4 cover. This guide has not verified that server behavior. For the supported cross-generation pairing, see [the manual subsystem update](/core/firmware-updates/manual-update/).

</Callout>
