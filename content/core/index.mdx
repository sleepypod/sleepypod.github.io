# sleepypod Core

<Callout type="info">
  No Pod yet? Open the [live demo](https://sleepypod.vercel.app): the real Core web app running with
  sample data.
</Callout>

The foundation of the system. Core runs on the Pod's embedded Linux and provides a local web app, hardware control, scheduling, biometrics processing, and an API for your other controls.

## See what’s new

[Watch the overview video](/core/tour/), then explore the [temperature Stage](/core/temperature/#explore-the-temperature-stage), [experimental Base controls](/core/base/), and [schedule end actions](/core/schedules/#what-happens-at-the-end).

## What you can do

- Set temperature and power independently for the left and right sides.
- Schedule temperature changes, power, vibration alarms, and maintenance.
- Explore sleep sessions, heart rate, heart rate variability, and breathing trends.
- Connect Apple Home or Home Assistant through opt-in local bridges.
- Inspect device health and sensor activity from the web interface.

## Guides

**Set up:** [open the Pod and get root](/core/root-access/), then [install and update Core](/core/installation/). Already running free-sleep? See [Migrating from free-sleep](/core/migrating-from-free-sleep/).

**Use the app**, one guide per section:

- [Temp](/core/temperature/): Stage, thermal view, temperature, power, manual holds, and Resume.
- [Base (experimental)](/core/base/): positions, presets, and whole-bed movement schedules.
- [Autopilot](/core/autopilot/): rules, dry run, backtests, and diagnostics.
- [Schedule](/core/schedules/): nightly curves and vibration alarms.
- [Sleep](/core/biometrics/): nights, stages, vitals, and data export.
- [System](/core/system/): the Dashboard and a page for each System tab.
- [Settings](/core/settings/): a page for each Settings section, from [Appearance](/core/settings/appearance/) to [Gestures](/core/settings/gestures/) and [Updates](/core/settings/updates/).

**How it works:** the [Autopilot engine](/core/autopilot-engine/), [how your data flows](/core/data-flow/), the [HomeKit and MQTT reference](/core/integrations/), and [MCP for agents](/core/mcp/). For deeper implementation details, see [Developers](/developers/).

## How the pieces connect

Core sends hardware commands through the Pod's DAC socket. Its scheduler operates on the device. Independent Python modules process sensor data into a separate biometrics database. The web app, iOS app, and Dial consume Core's state and API.

For implementation details, read the [architecture reference](/developers/architecture/).
