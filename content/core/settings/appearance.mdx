# Appearance

**Settings → Appearance** changes how this browser shows the app. It does not change anyone else's view or any saved temperatures, except for **Units**, which applies to the whole Pod.

## Temperature control

Choose how the Temp screen looks on this device. Each choice shows a live preview.

| Option                 | What you get                                                            |
| ---------------------- | ----------------------------------------------------------------------- |
| **Dial** (default)     | A round dial you drag, with Cooler and Warmer buttons                   |
| **Slider**             | A vertical slider, with Cooler and Warmer buttons                       |
| **Now · Night · Dawn** | A stepper that changes the temperature now, or tonight's saved schedule |

See [Temp](/core/temperature/#choose-your-controls) to compare the three.

## Show as

| Option                | Example | Meaning                                                         |
| --------------------- | ------- | --------------------------------------------------------------- |
| **Degrees** (default) | 74°F    | The actual target temperature                                   |
| **Offset ±**          | −6      | Whole degrees away from 80°F, where 80°F shows as 0             |
| **Eight Sleep**       | −2      | Eight Sleep's −10 to +10 level scale; one level is about 2.75°F |

This only changes how numbers appear. Schedules and the API still store temperatures in Fahrenheit.

On the phone Settings overview, **Time format** also offers 12-hour or 24-hour display. This is a Pod-wide setting, also available in [Device](/core/settings/device/#clock-and-schedule-defaults).

## 3D stage

**Zone readings** controls when the six surface readings appear: **On hover**, **Always**, or **Off**. **Auto-return** brings the camera home after a pause. These are browser preferences for the [temperature Stage](/core/temperature/#explore-the-temperature-stage), not changes to the sensors.

## Display

- **Theme:** **Auto** (default) follows your device's light or dark setting. **Dark** and **Light** override it.
- **Units:** **°F** (default) or **°C**. This changes the unit for the whole Pod, on every device. It is the same setting as **Temperature unit** in [Device](/core/settings/device/).

Temperature control, Show as, and Theme are saved in this browser only. If you clear your browser data or use another device, you will see the defaults again.
