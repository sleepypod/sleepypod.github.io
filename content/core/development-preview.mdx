## Other changes in this preview

See [Settings](/core/settings/) for side tabs, [Away mode](/core/settings/sides/#away-mode), and [MCP for agents](/core/mcp/). Network access is checked against the Host/Origin allowlist; custom hostnames and reverse proxies may need configuration in the deployment guide below.

The release also improved quiet-sleeper re-entry, bed-empty transitions, pump-time movement scoring, and handling of unknown calibration quality. These changes do not promise accurate classification for every sleeper.
